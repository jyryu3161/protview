## Adopted method

`compute_interface_sasa` runs synchronously through `Run.call` on one `prepared_structure@1` and one exact full `ResidueRef` ligand. It uses FreeSASA `calcCoord` on explicit selected protein and ligand heavy-atom coordinates, with Lee–Richards, 100 slices, a 1.4 Å probe and one thread. The method ID is `freesasa_lee_richards_v1`. Gemmi `Element.vdw_r` values for C, N, O, S, P, F, Cl, Br and I are persisted with the result, as `gemmi_vdw_elements_v1`; unsupported elements fail. There is no Shrake–Rupley production path, inferred radius, isolated-atom special case or output correction.

The protein set comprises canonical 20 amino-acid polymer residues across included chains. The ligand is the exact selected nonpolymer instance. Water, ions, other ligands and nonprotein components are excluded and enumerated by complete residue reference and atom count. Hydrogen and deuterium are excluded. The analysis supports up to 6,000 selected heavy atoms, coordinates within ±1,000,000 Å, and a selected bounding-box extent of at most 10,000 Å. Duplicate identities, unresolved altlocs, coincident or numerically indistinguishable centers, nonfinite positions and invalid radii fail before the native SASA calculation. All three native inputs share a recorded origin translation; the immutable prepared coordinates are unchanged.

The result retains each atom’s full residue identity, name, serial, element, original coordinates, radius, isolated/bound/buried values and index. It records all protein-residue rows, including zeros, and the three native calculations: SASA(P), SASA(L) and SASA(P∪L). Protein burial, ligand burial and total SASA loss are separate Å² quantities. The area tolerance for accounting is 1e-6 Å² absolute plus 1e-10 relative; exact stored values are not rounded. Two-decimal report rendering uses decimal ROUND_HALF_UP. A zero burial is a successful measurement.

The `method_report_manifest@1` report binds the selected result, original source, preparation manifest, complete ligand, method/radius/selection metadata, full atom and residue data, source field claims, native units, call/event provenance and the separately unavailable Rosetta protocol snapshot. Markdown displays every protein residue; JSON contains all exact atom and residue rows. Existing `report_manifest@1` objects remain readable without modification. Saved method reports load from immutable events/objects without calling FreeSASA. The UI includes current and selected historic SASA results, exact-input computation from a selected contact result, table focus after viewer readiness, explicit report creation, preview and downloads.

## Limits and gate

SASA measures probe/radius/resolution-dependent solvent-accessible geometry for the named two partners. It does not include excluded crystal components or establish binding energy, affinity, stability or a validated hydrogen bond. The method uses a bounded synchronous native call with wall accounting; it makes no claim of hard process cancellation. The default run remains `local_only`. Rosetta protocols remain separately unavailable and do not acquire SASA values under energy labels.

The initial Sol implementation passed55 targeted backend tests, Ruff,11 frontend tests, TypeScript typecheck and the production build.
