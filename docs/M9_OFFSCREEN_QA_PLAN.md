The suite must fail a case when native observation, actual browser download, or prerequisite source is absent. Read-only API inspection can verify durable objects and downloads; application mutations are driven through visible Electron UI actions. Fault routes may return an explicitly labeled 503 or delay an unchanged real response; they never supply fabricated scientific success. A WebGL loss fixture must use the actual context extension and be recorded as fixture-induced. The JSON sidecar is the stored manifest, and a screenshot is viewing provenance rather than new molecular measurement.
