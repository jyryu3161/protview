## Fixed invocation and native semantics

Run in a private job root with private TMPDIR and fixed basename:

```json
["<configured-pinned-fpocket>", "-f", "protein.pdb", "-m", "3.4", "-M", "6.2", "-D", "2.4", "-C", "s", "-e", "e", "-i", "15", "-p", "0.0", "--number_apol_asph_pocket", "3", "-v", "300", "-w", "p"]
```

The probe ran the same numerical configuration with short `-A 3`, but source audit found that short A is absent from the pinned getopt string even though its switch/default exists. The contract therefore uses the declared long option `--number_apol_asph_pocket 3`; Sol must execute and verify this corrected argv before acceptance. The probe does not prove short A was honored; default3 masked that risk. The intended flags set sphere radii3.4–6.2 Å, clustering threshold2.4, single-linkage/Euclidean clustering, minimum15 spheres, apolar proportion0, apolar neighbor parameter3, volume Monte Carlo iterations300 and PDB output. Record remaining fixed release defaults from `init_def_fparams`/headers in the method manifest, including density0.7 and basic volume division−1; verify installed supported build, not obsolete help comments. No user-supplied argv/config file, chain-as-ligand option, external topology, interaction grid or arbitrary output mode. [Pinned parameters](https://github.com/Discngine/fpocket/blob/4.2.3/headers/fparams.h).

Source4.2.3 seeds C RNG from time in utils/voronoi paths. There is no selected supported explicit-seed control. Store `seed_control=unsupported`, `fresh_execution_deterministic=false`, full native output/hash and method build. A cached completed call and replay return identical stored results; independently requested fresh runs can differ, particularly native Monte Carlo volume. No repeat-until-desired-pocket behavior, output tuning or fake fixed seed. Sorting parsed rows for stable serialization does not make the engine deterministic. [Random utility](https://github.com/Discngine/fpocket/blob/4.2.3/src/utils.c), [Voronoi implementation](https://github.com/Discngine/fpocket/blob/4.2.3/src/voronoi.c).

## Strict output and empty-result classification

Read only known files from `protein_out` under the owned job root. Reject symlinks/hardlink escapes, special files, unexpected executable payload use, recursive paths, duplicate ranks, duplicate/unknown fields where schema forbids them, nonfinite/out-of-bound coordinates, malformed records and output resource overrun. Never execute generated PyMOL/VMD scripts. Store bounded raw native files as evidence bytes, not executable viewer commands.

For every `Pocket N` block in `protein_info.txt`, require matching `pockets/pocketN_vert.pqr` and `pocketN_atm.pdb`, one-to-one rank membership, nonempty valid spheres and lining atoms. Reconcile reported sphere count to records. Parse PQR coordinates and radius by its exact supported format; its radius is not a B-factor. Map every lining record uniquely by synthetic chain/residue/name/element to projected input and check coordinates at output precision. Serial numbers can be renumbered by fpocket and are not sufficient mapping keys. No minimum-distance nearest match or fallback to original residue display string. Require every lining atom within the selected projected source, and deduplicate membership only with an explicit native-record policy. Native rounded radius can differ from full-precision cutoff at the final decimal; tolerance must reflect PQR precision rather than unjustified rejection.

A native empty success is recognized only on exit0, a present regular zero-byte `protein_info.txt`, a valid header-only `protein_pockets.pqr` with zero atom records, no per-pocket geometry/atom files, and the supported no-pockets diagnostic from stdout. The actual small probe produced `No Pockets Found while refining` plus `No pocket to reindex.`. Record that diagnostic and empty-output manifest. Missing directory/files, partial rank files, killed process, nonzero exit or arbitrary empty stdout are failures. A different future empty convention needs a reviewed parser version, not a permissive fallback. Successful empty result stores `null_result=true`, total0 and full input/method provenance.

`pocket_set@1` contains source/model/manifest handles, protocol/dependency manifest, native rank, per-pocket sphere centers/radii, exact source atom/residue membership, accepted native descriptors, raw-file hashes, total count, units/limitations, and result completeness. Initially expose native Score (dimensionless), Druggability Score (dimensionless, explicitly detector-specific), Number of Alpha Spheres (count), Total SASA (Å²) and Volume (Å³). Confirm descriptor implementation/units against pinned source before exposing; retain other raw descriptors only as opaque native evidence, not guessed units. Native volume is an estimator, not an analytical union-of-spheres volume. An optional display center is explicitly computed arithmetic mean of stored sphere centers, unitÅ, method named, not attributed to fpocket.

Persist complete bounded result, at most200 pockets and50000 total spheres; exceed is resource_exceeded, never silently truncate science. UI top-k defaults10, range1–50 and <=total; `displayed_count`, `total_count` and display truncation are distinct from engine result completeness. Preserve native ranking, including ties. Derived display sphere union/mesh is visual geometry and is not used to recompute native volume.
