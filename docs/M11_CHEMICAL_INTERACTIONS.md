# M11 chemical interactions UI behavior

Status: frontend controls are implemented against the Astra-approved transport in `M11_BACKEND_API.md`; actual backend/browser validation and the M11 phase gate remain pending. The scientific authority is `M11_CHEMICAL_INTERACTIONS_CONTRACT.md`. This document describes intended UI behavior, not a measured result.

The chemical workspace has three distinct views: input preparation, a validated local chemical source, and immutable assignments. A create-new path combines the selected prepared receptor and one explicit-H **V2000** SDF record in their supplied common coordinate frame; V3000 is unsupported. An attach-existing path maps the exact selected ligand instance to all SDF heavy atoms and handles supplied or replaced ligand H explicitly. The derived source retains the receptor coordinates and selected SDF conformer coordinates without alignment; every mapped source site must agree within 0.002 Å. Both paths show the full mapping, included/excluded atoms, connectivity and H policy before the first expensive job. Known terminal extensions can be selected from preview; a custom declaration resolves exact supplied terminal protein residue atoms and shows their attachment and extension bonds. Unfamiliar undeclared extensions cannot be exhaustively detected, so completeness is user-declared. The preparation description and pH field are local, unverified annotations; the preview and eventual report state that no protonation or optimization was performed and that inferred receptor bond orders/charges are not supplied experimental truth.

The input form keeps an explicit source mode, prepared receptor/model, ligand SDF/record, ligand instance, connectivity source, mapping, H policy and separate completeness acknowledgement. Missing prerequisites explain the disabled action. Preparation/conversion and fingerprint detection are separate durable job stages with their own approval, running, cancel, failed, retry and done states. A detected result cannot be requested until a valid immutable graph/source has been accepted. Existing result history reopens source, graph and assignments through read endpoints without submitting either job.

Chemical display is a separate local intent with its own generation and validated source bytes/catalog. Its read-only source-linked preparation manifest shows the saved ligand instance, SDF record and unverified pH note alongside the manifest handle/hash. It is not an M8 viewer-intent session, M9 saved scene or M10 comparison source. Local representation, camera movement and exact assignment-row focus remain usable. A selected row displays category, ligand and receptor identity, role-labeled D/H/A atoms, native indices, D···A or other endpoint meaning, distance in Å, optional angle in degrees and the actual annotation from stored coordinates. Category filters and pagination never alter immutable assignment identity. A zero-row valid result has a neutral scientific-null state; chemistry errors and unavailable capability remain visibly different.

While a chemical source is displayed, M8 prompt, M9 Save and PNG/JSON figure export, and M10 Measure/Add-to-comparison are disabled with the source-kind/schema reason even when annotations are hidden. Selecting an older supported M9 scene exits chemical display, restores the ordinary source/session and its compatible controls. Original/prepared/minimized source allowlists and old report bytes remain unchanged.

The report is an immutable field-validated chemical-interaction report with source/graph/method/dependency provenance, criteria, counts, exact row evidence and explicit inference limitations. Markdown and JSON downloads are served from stored bytes. All actions are local-only; no provider or model call is part of this workflow.

The closed tool registry adds the two reviewed M11 durable job specs, moving from 19 to 21 entries. This is a job-only admission extension; ordinary `Run.call`, including dry-run, does not admit preparation or detection through those specs.
