# 0005. 기본 로컬 전용, 외부 요청은 단일 게이트, 뷰어 프롬프트는 동의 시에만

- 상태: 채택 (M3 2026-09-24, M8 확장 2026-09-25). 과학 데이터 전송 금지 부분은 0015(2026-09-29)로 대체됨. 단일 게이트·감사 기록·키 보호는 유지.

## 배경
연구실의 미공개 구조와 서열이 외부로 나가면 안 되고, 기본 작업 흐름은 키나 네트워크 없이 끝나야 한다. 한편 M8에서 사용자는 자연어로 뷰어를 조작하는 실제 모델 호출을 원했다.

## 결정
- 새 run은 항상 `local_only`로 시작한다. 외부 HTTP는 `EgressGate`만 보낼 수 있다.
- 외부로 보내는 상태는 키 이름을 걸러내는 방식이 아니라, 스키마 허용 목록으로 새로 만든다.
- M8: run별로 온라인 모드와 뷰어 전용 동의를 명시적으로 켜면, 사용자가 입력한 문장과 제한된 별칭 카탈로그만 보낸다. 이 동의는 과학 계산 승인을 주지 않는다.

## 검토한 대안
- 키 이름 기반 필터(참고 구현): 다른 키 이름 아래 숨은 좌표나 민감 문자열을 놓친다.
- 키가 있으면 자동으로 온라인: 사용자가 모르는 사이에 전송된다.
- 뷰어 요청도 숫자 집계만 보내기: 자연어 조작이라는 목적 자체가 불가능하다.

## 결과
- 사용자가 입력한 문장 안의 민감 정보까지는 막을 수 없다. UI가 전송 내용을 미리 보여 주는 것으로 대신한다.
- 새 외부 기능(데이터베이스 조회, 모델 가중치 다운로드 등)도 같은 게이트를 거쳐야 하며, 별도 투영과 동의 설계가 필요하다.
