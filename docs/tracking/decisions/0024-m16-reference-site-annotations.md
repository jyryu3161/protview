# 0024. M16 참조 주석은 고정 부위 10개를 같은 구조의 기하 접촉과 함께 보여 준다

- 상태: 채택 (사용자 결정 2026-09-30, M16 명세 확정 때)

## 배경
M16의 여는 시나리오는 "kinase hinge 상호작용 논문용 시각화"다. M15가 잔기마다 KLIFS 번호(참조 스냅샷 값)를 붙였고, M1이 리간드와의 기하 접촉(계산값)을 만든다. 둘을 한 화면·그림·보고서에 놓으면 참조값과 계산값이 섞이거나, 기하 접촉이 수소결합으로 읽히거나, KLIFS 자리 이름이 잔기의 역할 주장으로 읽힐 위험이 있다. 사용자는 모든 질문에서 범위를 작게 하는 추천안을 골랐다. 틀린 값을 보여 주느니 없음·계산하지 않음을 이유와 함께 보여 준다.

## 결정
- **부위 목록**: `kinase_key_sites@1` 10자리(III.17, αC.24, GK.45, hinge.46–48, xDFG.80–83)를 코드 상수로 고정하고 결과에 그대로 기록한다. 표기는 M15 `klifs_label`과 문자 그대로 같다. 관용 이름(촉매 Lys 자리 등)은 문서 설명용이며 화면·보고서·결과에 넣지 않는다. 85개 포켓 전체·구역 선택 표시, 사용자가 고른 잔기를 부위로 표시하는 길은 없다.
- **같은 구조에만**: 번호 대응·접촉 결과·보기 소스의 구조 handle이 모두 같아야 한다. 원본 구조로 만든 대응을 전처리 구조에 입히지 않는다(`structure_mismatch`). 접촉과 함께 주석하려면 전처리 구조로 대응을 만든다.
- **기하 접촉만**: M1 `interaction_set@1` 행만 쓴다. ProLIF(M11) 강조는 하지 않는다. 극성 접촉(`polar_contact`)은 원자 쌍마다 점선과 저장된 거리, 다른 접촉 잔기는 색으로만 강조한다. 브라우저는 거리를 재지 않는다.
- **새 불변 결과**: 값싼 도구 `annotate_reference_sites` → `reference_site_annotation@1`. 부위 상태는 `annotated | absent`, 없음 이유는 닫힌 집합 4개(첫 해당 이유 하나). 같은 KLIFS 번호의 대응 행이 둘이면 고르지 않고 실패한다. 계산하지 않음·검사하지 않음·접촉 결과 없음은 0이 아니다. 접촉 결과 없는 주석·보고서도 허용한다. 새 보고서 `analysis_type: "reference_site_annotation"`.
- **저장된 보기와 그림**: 주석이 켜진 보기는 `viewer_scene@2`(`annotation{handle, legend}`), 그 그림은 `viewer_figure@2`. 주석이 꺼지면 `viewer_scene@1`·`viewer_figure@1` 바이트 그대로다. 복원은 저장된 주석을 다시 그린다(도구를 다시 실행하지 않음).
- **범례 기본 켬**: PNG를 앱 밖에서 봐도 점선이 수소결합으로 읽히지 않도록 "점선: 기하 극성 접촉(원자 거리), 수소결합 판정 아님"을 기본으로 그려 넣는다. 사용자가 끌 수 있고 그 값을 보기에 기록한다. 문구를 바꾸거나 없애는 방향으로 고치지 않는다.
- **배타 규칙**: 포켓 오버레이와 주석은 동시에 켜지지 않는다. M10 비교를 시작하면 주석이 꺼지고 비교 중에는 켤 수 없다. 주석이 켜진 동안 M8 자연어 뷰어 요청은 막는다(주석 내용을 외부로 보내는 길은 M24 일). M9 보기 저장·PNG는 허용한다.
- **그림 상한 유지**: 로드맵 M16의 "고해상도 그림 검토"는 "올리지 않음"으로 정했다. 한 변 64–2048 px, 400만 픽셀 이하, PNG 8 MiB, run당 그림 100개·PNG 총 64 MiB 그대로다. 실제로 써 보고 부족하면 따로 올린다.
- **지식 탭**: 바꾸지 않는다. 지식 탭 체인 목록을 도구 규칙으로 바꾸는 findings 항목은 다시 미룬다(틀린 대응이 생기는 문제가 아님).

## 검토한 대안
- ProLIF 상호작용 강조: 화학 입력 준비가 필요하고 화학 작업 화면 범위다. 사용자가 고르지 않았다.
- 85개 포켓 전체·구역 선택 표시, 사용자 지정 잔기: 범위가 커지고 참조값 없는 잔기에 KLIFS 이름이 붙을 수 있다.
- 원본 구조 대응을 전처리 구조에 옮기기: 잔기 식별자 대응 규칙이 새로 필요하다.
- 범례 없이 그림 저장: 논문 그림에서 점선이 수소결합으로 읽힐 수 있다.
- 포켓 후보와 hinge 주석을 한 그림에: 이번 단계에서 하지 않기로 했다(빠뜨린 것이 아님).

## 결과
- 착수 확인에서 ATR 5YZ0:A의 GK.45·hinge.46–48이 손 대조·제품 규칙·KLIFS 구조별 표 셋 다 같았다. `linker.49` 차이는 부위 목록 밖이라 규칙을 바꾸지 않았다(`docs/qa/m16-annotations-20261001/preflight.txt`).
