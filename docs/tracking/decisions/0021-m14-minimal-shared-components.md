# 0021. M14는 지금 여러 탭이 같이 쓰는 것만 공용으로 꺼낸다

- 상태: 채택 (사용자 결정 2026-09-29, M14 명세 확정 때)

## 배경
로드맵 M14 행은 "공용 구성 요소(소스·보기·작업·보고서)"를 약속한다. 그런데 M14 시점에 실제로 기능이 있는 탭은 구조 분석과 지식·보고서의 보고서 목록뿐이다. 메인 화면(`frontend/app/page.tsx`)은 약 1,900줄이고 M8–M13 오프스크린 검사가 그 구조에 묶여 있어, 미리 넓게 쪼개면 회귀 위험이 크다.

## 결정
- M14는 현재 run 정보, 예산 표시, 보고서·그림·완료된 흐름 요약 목록 읽기만 공용으로 꺼낸다(`WorkspaceTabs`, `ReportLibraryPanel`, `src/lib/workspace-tabs.ts`, `src/lib/report-library.ts`).
- 소스 선택, 저장된 보기, 작업 패널, 계획·실행 패널의 공용화는 그것을 처음 필요로 하는 탭 단계(M15 이후, 작업이 여러 탭에서 생기는 M17 이후)로 미룬다.
- 같은 이유로 다음도 M14에서 하지 않는다: 다른 탭에서 run 전환(run 선택은 구조 분석 탭에만), 다른 탭에 있을 때 구조 분석 쪽 상태 알림, run 전체 작업 목록, 탭별 주소, 보고서 Markdown 렌더링.

## 검토한 대안
- 소스·보기·작업·보고서를 모두 독립 구성 요소로 미리 분리: 뒤 단계가 편해지지만 메인 화면을 크게 고쳐야 하고 M8–M13 회귀 검사량이 크게 는다.

## 결과
- 로드맵 M14 행의 공용 구성 요소 중 소스·보기·작업은 아직 공용이 아니다. 뒤 탭 단계가 착수할 때 이 결정을 다시 본다.
- M14는 백엔드를 바꾸지 않았고, 기존 M8–M13 오프스크린 스크립트도 고치지 않고 통과했다(`docs/tracking/m14-acceptance.md`).
