# 0012. 제품의 실제 모델 호출은 매번 사용자가 횟수를 정한다

- 상태: 채택 (사용자 확인 2026-09-27)

## 배경
M8에서 실제 OpenRouter 호출 4회를 QA에 할당했고, 모두 썼다. 호출은 비용이 들고, 사용자가 입력한 문장이 외부로 나간다.

## 결정
개발·검증 중 제품이 실제로 외부 모델을 호출해야 하면, 필요한 횟수와 이유를 사용자에게 말하고 한도를 받은 뒤, 그 안에서만 호출한다. 오류·경합·실패 경우는 fixture transport로 테스트한다. 개발 도구로 쓰는 Claude 자체는 이 제한과 관계없다.

## 검토한 대안
- 개발 중 자유롭게 호출: 비용과 전송이 통제되지 않는다.
- 실제 호출 전면 금지: alpha API의 실제 동작을 검증할 수 없다.

## 결과
- M13의 모델 보조 계획은 새 호출 할당과 별도 투영·동의 설계가 필요하다.
- 한도를 다 쓰면 결과를 그대로 보고하고, 새 run을 열어 몰래 더 호출하지 않는다.
