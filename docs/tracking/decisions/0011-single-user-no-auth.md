# 0011. 인스턴스당 한 사람, 인증 없음, loopback 바인딩

- 상태: 채택 (사용자 확인 2026-09-27)

## 배경
연구실·팀 구성원이 각자 자기 컴퓨터나 서버에 설치해서 쓴다. 외부 공개 여부는 아직 정하지 않았다. 여러 사람이 계정을 가진 서버에서는 같은 서버의 다른 사용자도 loopback 포트에 접속할 수 있다.

## 결정
인스턴스 하나는 한 사람만 쓴다. 서버도 한 사람이 쓰는 경우에만 실행하고, SSH 포트 포워딩으로 접속한다. 계정, 인증, 사용자 간 데이터 분리는 구현하지 않는다.

## 검토한 대안
- 로그인과 사용자별 분리 구현: 공유 서버에서는 안전하지만, 현재 사용 방식에서는 필요 없는 복잡도다.
- `0.0.0.0` 바인딩으로 팀 공유: 인증 없이 모든 run이 노출된다.

## 결과
- 여러 사람이 계정을 가진 서버, 외부 공개, 팀 공유 인스턴스는 지원하지 않는다. 그렇게 바꾸려면 인증, run 소유권, 경로 격리를 새로 설계해야 한다.
