# 0010. Git 기록을 소급해서 만들지 않는다

- 상태: 채택 (2026-09-24)

## 배경
M0–M5는 단계 게이트와 검토로 진행했지만, 단계별 브랜치나 커밋은 없었다.

## 결정
`d22fe15`를 실제 기준선으로 둔다. M6부터는 이전 단계에서 실제로 승인된 커밋에서 `phase/m<N>-<slug>` 브랜치를 만든다. 메인 세션은 실제로 일어난 커밋만 기록한다.

## 검토한 대안
- M0–M5 브랜치·커밋을 나중에 재구성: 존재하지 않았던 기록을 만드는 것이다.

## 결과
- 공유 소스가 바뀌면 과거 검토 해시가 오래된 상태가 된다. 새 작업의 검토에서 바뀐 범위를 명시적으로 대체하고, 과거 기록은 그대로 둔다.
