# 전체 로드맵 (M12 이후)

기준: 2026-09-29 사용자 결정. M12와 M13은 기존 설계대로 유지하고, 그 뒤 단계를 작게 나눠 늘린다. 각 단계의 세부 구현(엔진 버전, 스키마, 파라미터 기본값, 화면)은 그 단계를 시작할 때 사용자와 함께 정한다. 이 표는 순서와 범위의 약속이지 구현 명세가 아니다. 배경 분석·출처·라이선스 조사·결정 후보 전체는 `docs/tracking/roadmap-analysis-20260929.md`에 있다. M29(구조 보완)는 이 결정 뒤 M28 판정을 받고 사용자가 "이 플랫폼은 범용 플랫폼인데, 특정 단백질만을 대상으로 하는게 아니야."라고 요청해(2026-10-12~13) 더한 단계이며, 아래 표의 M29 행은 기록 초안이다(판정 `검증 통과, 사용자 확인 대기`, 결정 0037).

## 완성의 정의

탭 네 개가 각자 제 일을 하고, 아래가 실제 데이터로 한 번 끝까지 돌아가 검토를 통과하면 완성이다.
1. **구조 분석**: 구조를 열어 부위·상호작용·표면·공동을 로컬 계산으로 보고 논문용 그림을 낸다.
   - M28 주석(`완성(범위 명시)`, 사용자 확인 2026-10-12): 분기 A의 A1 → A2 → A3 → A4 → A6이 공개 1M17에서 모두 `pass`였다(전처리, AQ4 인스턴스의 기하 접촉, 단백질–리간드 SASA, fpocket 포켓 후보와 알파 구 오버레이, KLIFS 참조 주석·저장된 보기·PNG + 출처 JSON 그림, 로컬 계산·외부 요청 0). [범위 표](m28-acceptance.md#범위-표) 13번.
2. **지식**: 그 부위가 계열 지식(kinase·enzyme·GPCR 순서 후보)에서 무엇인지 잔기 단위로 확인한다.
   - M28 주석(`완성(범위 명시)`, 사용자 확인 2026-10-12): 키나아제 A5 → A6 → A7(1M17 A·1FIN A·C·1MQ4 A 번호 대응, 참조 주석, 로컬 `kbase_kinase`를 격리 설치한 전례 세트의 개수를 독립으로 센 값과 대조)과 효소 A8(1S9I·1A30·1A4I, M26 보관 실세트의 격리 복사)이 모두 `pass`였다. GPCR은 범위 밖이다. [범위 표](m28-acceptance.md#범위-표) 8·12번.
3. **리간드 설계·탐색**: 바꿀 부위·building block·reaction rule로 후보를 만들고 필터·도킹으로 점수 표를 낸다.
   - M28 주석(`완성(범위 명시)`, 사용자 확인 2026-10-12): 분기 B의 B2 → B3 → B4가 `pass`였다(ProLIF 공개 예제 준비 수용체, 공개 파생 부모 SDF, 합성 표시 building block·반응 규칙으로 후보 14개, 실제 qvina 단독 도킹과 재제출 재사용, 일괄 점수 표). [범위 표](m28-acceptance.md#범위-표) 3·11번.
4. **단백질 공학**: 촉매·보호 잔기를 지킨 채 변이 후보를 만들고 변이 구조를 모델링·평가한다.
   - M28 주석(`완성(범위 명시)`, 사용자 확인 2026-10-12): 보호 C1(1A30, M26 대응됨 행 → M20 v2 `catalytic_residue`)과 모델링·평가 C2 → C3(1UBQ, PDBFixer + OpenMM, 같은 조건 도킹 짝은 합성 표시 페놀 SDF)이 `pass`였다. M7을 통과하는 로컬 공개 구조가 1UBQ뿐이라 두 반쪽은 서로 다른 구조에서 보였다. [범위 표](m28-acceptance.md#범위-표) 1·2·14번.
5. 3·4에서 GA 설계와 JEV 설계를 각각 파라미터를 바꿔 가며 예산·승인 안에서 돌린다.
   - M28 주석(`완성(범위 명시)`, 사용자 확인 2026-10-12): 리간드 B5(GA 설정 둘)·B6·B7(루프 탐색형·활용형)과 단백질 C4(서열 GA 설정 둘)·C5·C6(루프 두 목표)이 fixture 서버로 `pass`였고, 실제 JEV 호출 2회(`L-B7` 리간드 활용형, `L-C6` 단백질 탐색형)가 둘 다 `completed`였다. 한도 증액은 사람 클릭으로만 했다. [범위 표](m28-acceptance.md#범위-표) 5·6번.
6. 모든 수치는 handle·필드·단위로, 모든 인용은 출처·버전으로 역추적되는 보고서를 얻는다.
   - M28 주석(`완성(범위 명시)`, 사용자 확인 2026-10-12): 분기 A–C의 저장 보고서 28개(live 8개)가 역추적 감사 다섯 검사(다시 열기, 근거 객체, 주장 필드, 참조값 출처, 증거 종류 섞임)를 모두 통과했고 보고서 목록(X1-A·B·C, B8, C7)과 JSON 내려받기 해시가 맞았다. M20 보고서는 참조값을 인용할 때 출처표가 든 형식 `mutation_candidates_markdown@2`로 고쳤다. [범위 표](m28-acceptance.md#범위-표) 10번.
