## Actual implementation reviewed

The browser sends a bounded user-entered prompt and exact local session identity. The backend derives a strict viewer-only projection and safe alias catalog from the displayed immutable structure. Coordinates, source paths, opaque handles, sequence, atom/residue names and arbitrary context are absent from model state. Typed input text is explicitly disclosed to the user rather than falsely described as anonymized. Unsafe identifiers cannot become criteria; oversized catalogs require scope for targeting while targetless controls remain usable.

The existing EgressGate owns the fixed Decisions endpoint and pinned request/served-model policy. Viewer-only consent is durable, default-off and separate from scientific-job approval. Four physical attempts per run, reservation/settlement, wall deadline, cancellation and uncertain-delivery behavior survive reopening. No provider pin/destination, fixture transport or arbitrary tool is selectable from the production request. Local commands remain explicitly local; model output compiles only to bounded representation, selection and camera commands, without JavaScript, files, shell, reports or expensive-job dispatch.

Admission and generation CAS use a short transition lock; physical execution retains the existing long run owner. Session/client/generation/source/catalog/action-revision checks precede actual Mol* work and acknowledgment. Manual intent wins. Switching a source while a model request owns the run can honestly reject a new scientific load as busy; the actual same-model retry after release was verified, without weakening serialization or applying the old command.

A browser acknowledgment is execution evidence supplied by the client, not a proof of scientific correctness. The offscreen renderer independently observed actual representations, loci, camera and pixels. Partial application followed by Stop or lost ACK now reconciles only axes actually attempted, from a guarded native snapshot. Cancelled/detached records retain zero server ACKs; the toolbar and next projection reflect real state without inventing success. React prop-to-session synchronization is suppressed until this reconciliation commits, and later manual revision or source change invalidates stale callbacks.
